## ADDED Requirements

### Requirement: Worker Earning Profile Configuration
The system SHALL support attaching gig rate cards, default commission rules, and tip split preferences directly to the worker profile (`Employee` / `Worker Profile`).

#### Scenario: Assigning default gig rate to worker
- **WHEN** an owner creates or edits an entertainer profile
- **THEN** they can assign primary and secondary role rates (e.g. Lead Entertainer vs Support Staff) used as default dispatch wages
